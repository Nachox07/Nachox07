# Hi, I'm Nacho

## Lead engineer working on AI systems that run in production

I lead engineering at [OpenVPN](https://openvpn.net).

On my own time I run [Tardeo](https://tardeo.ai), a service that finds out what is
on in four Spanish cities. A vision model reads venues' public posts, extracts the
events, and publishes them to Telegram channels and a web agenda every day. It is
where I do my own work on evaluation: a labelled dataset at the real production
mix, misses and false alarms counted separately, prompt changes measured before
they ship, and model choices decided on numbers rather than impressions.

- Mostly TypeScript and Node.js, with Python and SQL
- Working on: retrieval over Tardeo's own agenda, and publishing the evaluation
  harness behind the extraction pipeline
